🚀 WorkNest – Android Service Booking App | Group Project (NIBM) 📱

Excited to share WorkNest, an Android service booking application developed as a group project at National Institute of Business Management (NIBM) using Android Studio.

WorkNest is designed to connect users with local service professionals such as electricians, plumbers, and more — making service booking simple, fast, and reliable.

This project gave me valuable hands-on experience in collaborative development, Android app architecture, and real-world problem solving.

🔹 Tech Stack

Android Studio

Java

Firebase

🔹 Key Features
✅ Secure user authentication (Sign up / Sign in)
✅ Browse and book service providers
✅ Live location integration for easy navigation
✅ Booking and service management system
✅ Customer support integration via WhatsApp
